# Migrating to v0.1.13

Standalone CLI runs no longer default to the shared `local-development-only`
control token. Each run now creates a random token and prints it in the startup
banner.

- If your app calls `startAgentBridge()`, no change is required.
- If your app manages the CLI as a separate process, pass a stable secret with
  `--token` or `AGENT_BRIDGE_CONTROL_TOKEN` and use that value for discovery.
- Do not store the token in source control or expose the loopback server through
  a proxy or tunnel.

The OpenAI image request schemas are otherwise backward-compatible. This
release adds `detail: "original"` when the installed Codex host advertises it
and allows the official default `tool_choice: "auto"` behavior for Responses
image generation.
